The Building Blocks of an AI Agent

An AI agent isn't one clever trick — it's five separate jobs working together, and each one can succeed or fail on its own.

the core

AI Agent

reasoning

LLM Core

Reads the situation and decides what to do next — the "brain" behind every choice.

context

Memory

Remembers past turns, facts, and outcomes so it doesn't start from zero each time.

capability

Tools

Calls APIs, runs code, browses the web — anything beyond just generating text.

strategy

Planning

Breaks a big goal into smaller steps and decides what order to do them in.

safety

Guardrails

Keeps actions in-scope, reversible, and checked before anything risky happens.
