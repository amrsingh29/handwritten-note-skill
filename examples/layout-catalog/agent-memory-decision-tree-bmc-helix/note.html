Which Memory Should Your AI Agent Use?

Not every agent needs the same kind of memory — three quick questions narrow it down to the right answer instead of reaching for the fanciest option by default.

question 1

Does it need to persist after this session ends?

no
✓ use this

Working Memory

A short-lived conversation buffer or scratchpad — cleared when the session ends. Cheapest option, and often enough.

yes
question 2

Is it exact facts, or fuzzy context?

exact facts
✓ use this

Structured Memory

A key-value or database record — user preferences, IDs, settings. Fast, exact lookups, no ambiguity.

fuzzy context
question 3

Is there a lot of it to remember?

not much
✓ use this

Rolling Summary

Compress older context into a running summary and carry that forward instead of the raw history.

a lot
✓ use this

Vector Memory

Embed and store it, then retrieve only what's relevant to the current query — scales to far more than fits in context.

✎ Most agents actually need two or three of these at once — this just tells you which one solves which problem.
