The OSI Model, Layer by Layer

Every time you load a page, your click passes through seven layers — from the actual electrical signal in the cable up to the words you read.

L7

Application

What you and your software actually interact with. HTTP, email, your browser.

L6

Presentation

Translates, encrypts, and compresses data so both ends can understand it. TLS encryption, JPEG/PNG encoding.

L5

Session

Opens, manages, and closes the conversation between two applications. login sessions, API sessions.

L4

Transport

Makes sure data actually arrives, in order, without gaps. TCP, UDP, port numbers.

L3

Network

Figures out the path across different networks to the destination. IP addresses, routers.

L2

Data Link

Moves data between two devices on the same local network. MAC addresses, switches.

L1

Physical

The actual electrical signal, light pulse, or radio wave — raw bits with no meaning yet. cables, fiber, Wi-Fi signal.

Read bottom to top on the way out, top to bottom on the way back in.

✎ Nobody actually builds strict OSI stacks anymore — but every real network still does all seven jobs.
